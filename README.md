# SAKA 한국생활체육총연맹 (Sport for All Korea Association)

세계생활체육연맹(TAFISA) 공식 하부 한국 총괄기관인 **SAKA(한국생활체육총연맹)**의 공식 웹사이트 메인 화면 템플릿 프로젝트입니다. 가볍고 빠른 로딩을 위해 복잡한 자바스크립트 프레임워크를 배제하고 HTML5, CSS3, Tailwind CSS CDN 및 Vanilla JS만을 활용하여 최고 수준의 비주얼과 웹 반응성을 제공하도록 설계되었습니다.

---


## ✨ 핵심 기능 및 디자인 아키텍처

### 1. 극대화된 웹 비주얼 (Visual Aesthetics)
* **Tailwind CSS 커스텀 테마**: SAKA 브랜드 아이덴티티인 신뢰감의 딥 네이비(`saka-navy`), 활력의 블루(`saka-blue`, `saka-sky`), 열정의 코랄 오렌지(`saka-accent`) 컬러셋을 연계했습니다.
* **유려한 백그라운드 모션**: 흐릿하게 회전하며 떠다니는 그라데이션 오브(Gradient Orbs)와 부드러운 펄스 애니메이션이 정적인 화면에 활기를 불어넣습니다.
* **글래스모피즘**: 네비게이션 헤더 및 핵심 컴포넌트에 미려한 투명 블러(`backdrop-blur`) 및 얇은 테두리 반사 효과를 적용해 모던하고 고급스러운 감각을 구현했습니다.

### 2. 고도화된 반응형 설계 (Mobile Responsiveness)
* **GNB 드롭다운**: PC 환경에서 메인 링크 호버 시 2차 메뉴가 자연스럽게 내려오는 마이크로 인터랙션을 반영했습니다.
* **모바일 슬라이드 아코디언**: 768px 이하 디바이스에서 최적화된 아코디언 드롭다운 메뉴로 전환되며, 모바일 스크롤 락 및 자연스러운 서랍 여닫이를 지원합니다.

### 3. 구조적이고 시맨틱한 마크업 (SEO & Accessibility)
* `header`, `main`, `section`, `footer` 등의 HTML5 표준 시맨틱 태그를 완벽 준수했습니다.
* 타이틀 태그 및 검색 최적화를 위한 메타 디스크립션을 기재하여 검색엔진 노출을 우수하게 대비했습니다.

## 🚀 빠른 시작 방법

1. 본 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 크롬, 엣지, 사파리 등 현대적인 웹 브라우저에서 직접 더블클릭하여 실행합니다.
3. 또는 VS Code의 **Live Server** 확장을 설치하여 실시간 렌더링 환경에서 웹페이지의 미려함을 체감하실 수 있습니다.
